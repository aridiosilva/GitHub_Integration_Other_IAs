# Aider

The official Aider CLI does not currently support MCP natively. Therefore,
there is no supported direct Aider CLI configuration for the GitHub MCP Server.

Use one of these alternatives:

1. Configure the Docker/stdio template in an MCP-capable AiderDesk client.
2. Use Aider for local editing and `gh` CLI for the branch/PR workflow.

Do not install deprecated GitHub MCP npm packages as a workaround.
